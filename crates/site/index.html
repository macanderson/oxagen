Every agent, in the open. Every key, one press away.

Most agents are a black box with a spinner. Stella puts the whole run on screen and hands you the controls. Arrow keys move between cards.

  • See the full reasoning

    Open the agent's complete chain of thought while it works, not a redacted summary after the fact.

    Ctrl+O

  • Inspect the task list, live

    See exactly what the planner decided to do, updating in real time as tasks start, finish, and get revised.

    Ctrl+T

  • Watch the swarm

    Every subagent, its status, and the exact tool call it's running right now. No more guessing what the fleet is up to.

    Ctrl+S

  • Kill a runaway agent

    When a run goes sideways, stop it dead. Two presses so you never fat-finger a good run into oblivion.

    Ctrl+X×2

  • Jump straight into $EDITOR

    Any file the agent touched is two keys from your editor. Review the change where you actually read code.

    Ctrl+V×2

  • Modes for how you work

    /plan to think before it acts, /debug to trace a failure, /verbose to turn the detail all the way up.

    /plan/debug/verbose

  • Extend it, don't fork it

    Drop custom slash commands, saved prompts, agent definitions (each with their own tools, skills, and MCP servers), and skills into .oxagen/. The /create-command, /create-agent, and /create-skill wizards scaffold them for you.

    .oxagen/commands.oxagen/agents.oxagen/skills

  • Browse the marketplace

    Find and install skills, MCP servers, agent definitions, and integrations from the terminal, all keyboard-navigable.

    /marketplace
// stack work endlessly

Pile on the work. Stella never gets overwhelmed.

You shouldn't have to wait for the agent to finish before you think of the next thing. Type it now. Stella figures out where it goes and keeps every step recoverable.

01 · triage

Never interrupt the flow

Submit a new prompt while the agent is busy and a triage agent decides where it goes: the queue, a background swarm, or an immediate answer. Stack work endlessly. The run never gets clobbered.

02 · scheduler

Sized to your machine

Stella measures free memory and CPU load, then sizes the swarm to fit. It runs as many agents as the machine can take, and no more, so your laptop stays usable.

03 · checkpoints

Crash-proof by design

Every step is checkpointed. If an agent dies mid-run, a replacement resumes from the exact step it stopped at. State is shared across the whole swarm, so nothing starts over.

// about

Oxagen builds the plumbing for AI agents.

Oxagen is the metered, governed, graph-grounded control plane for teams that build and resell AI agents. The neutral infrastructure layer, the Stripe for agents. We do the heavy lifting you never see, so your agents cost less, work better, and stay safe for the enterprise.

Stella is our open-source terminal coding agent. It's BYOK and model-agnostic on purpose: no account, no phone-home, no server dependency. Bring any provider's key, in any combination, and get a fast local-first agent that runs a whole swarm and keeps every step recoverable.

Vendor-neutral by design

Route to any model from any provider with your own keys. No gateway lock-in, no markup, no switch to rip out later.

Local-first context

Embeddings and a knowledge graph live on your disk, grounding every turn in your code. Nothing leaves the machine unless you say so.

Open protocols, not forks

Tools extend through MCP, context extends through the Open Context Protocol. Versioned, documented, and conformance-tested.

Built to be proven

A single static binary, sub-100ms cold start, aimed at #1 on SWE-bench Verified, reproducible from the public repo with just a model key.
