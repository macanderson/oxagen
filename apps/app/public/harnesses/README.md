# Harness marks

Claude Code, Claude, Codex, Cursor, and ChatGPT SVGs come from the [Lobe Icons collection](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons). The roadmap retained these assets on September 19, 2026. This directory copies them without changes. The MIT license is included. Brand marks remain their owners’ trademarks.

Original filenames: `claudecode-color.svg`, `claude-color.svg`, `codex-color.svg`, `cursor.svg`, and `openai.svg`. Monochrome variants use the retained light and dark assets. Colored variants keep their source colors. Stella uses the existing house mark at `/brand/stella-icon.svg`.

`HarnessIcon` selects an asset from a fixed registry. Recorded harness names never become asset URLs. Unknown harnesses use a neutral glyph. A logo identifies the harness brand, not its version, permissions, or enforcement tier.

`AgentAvatar` overlays this mark in the avatar's lower-left corner. `AgentCard` uses it in list, compact, and detail layouts. Spend uses it for run avatars. The badge follows the mockup's circular surface treatment and scales to 46% of the avatar, with a minimum diameter of 10 pixels. A missing harness draws no badge. Pass the recorded identifier, such as `claude-code`, rather than a translated label.
