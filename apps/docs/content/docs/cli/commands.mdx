## oxagen budget — spend ceilings

```bash
oxagen budget show [--json]
oxagen budget set --scope <scope> --period <period> --limit <usd> [flags]
```

Hard period-to-date spend ceilings that gate agent runs. `show` lists every configured ceiling with its live burn; `set` creates or replaces one. See [Spend budgets](/docs/cli/budget) for the full model.

| Flag (`set`) | Description |
|---|---|
| `--scope <scope>` | `org` or `workspace`. |
| `--period <period>` | The accounting period the ceiling resets on. |
| `--limit <usd>` | The ceiling, in dollars. |
| `--window-days <n>` | Rolling-window length, for window-based periods. |
| `--enabled <bool>` | Enable or disable the ceiling without deleting it. |
| `--json` | Machine-readable output. |

`set` requires org **Owner**, **Admin**, or **Billing** — it changes spend behavior.

## oxagen cost — project model cost

```bash
oxagen cost --in <tokens> --out <tokens> [-m <slug>] [--json]
oxagen cost --rates [--json]
```

Prices a token workload against the rate card baked into the CLI. With no `--model` it compares every priced model cheapest-first and reports the spread; with one it projects that model alone. `--rates` dumps the card.

This is **projection**, not observation — it makes no network call and needs no credential. For what was actually spent, use `oxagen budget show` (period-to-date burn) or `oxagen trace <executionId>` (per-run spend).

```bash
oxagen cost --in 200000 --out 40000
oxagen cost --in 200000 --out 40000 -m anthropic/claude-sonnet-5 --json
oxagen cost --rates
```

## oxagen trace — a run as a span tree

```bash
oxagen trace <executionId> [--json]
```

Renders one agent run as a span tree: each step, the tool calls it made, and any child executions it spawned, with timing. This is the *explain* surface — the evidence of what an agent did, reconstructed from the run ledger.

## oxagen graph — knowledge graph

```bash
oxagen graph search -q "<text>" [-l <labels>] [-n <limit>] [--json] [--quiet]
```

Bounded semantic (vector) search across the governed workspace context graph. `-l/--labels` takes a comma-separated list of domain labels (e.g. `Person,Company`); `-n/--limit` accepts 1–50 (default 10). See [Knowledge graph from the CLI](/docs/cli/knowledge-graph).

## oxagen memory & remember — agent memory

```bash
oxagen remember "<lesson>" [--class <class>] [--kind <kind>] [--enforcement <n>] [--node <ref>]
oxagen memory list|show|edit|salience|promote|demote|dismiss|candidates|citations|rm|import
```

The workspace's experiential memory. `remember` captures a lesson and infers its class and kind; the `memory` subtree curates them. See [Memory from the CLI](/docs/cli/memory).

| Subcommand | Description |
|---|---|
| `list` | List memories, filtered by `--class`, `--kind`, `--min-enforcement`, `--min-citations`, `--node`, sorted by `--sort`. |
| `show <id>` | One memory in full detail (id or publicId). |
| `edit <id>` | Change a memory's `--lesson`, `--kind`, or `--source`. |
| `salience <id>` | Adjust `--confidence`, `--enforcement`, or lifecycle `--status`. |
| `promote <id> --to <class>` | Raise to RULE or FACT, recording an auditable promotion event. FACT requires human confirmation. |
| `demote <id> --to <class>` | Lower to RULE or OBSERVATION, recording an auditable demotion event. |
| `dismiss <id>` | Remove from the promotion candidate queue (`--restore` puts it back). |
| `candidates` | Top OBSERVATION memories by citation pressure, ripe for promotion. |
| `citations` | Workspace citation analytics over `--days`: influence, compliance, most-cited, least-useful, most-violated. |
| `rm <id>` | Permanently delete a memory. |
| `import <files...>` | Bulk-import markdown rule docs as memories. Previews unless `--yes`. |

## oxagen init — link a project

```bash
oxagen init [--no-link] [--json]
```

Resolves an org and workspace (picker, or reused from an existing link) and writes `.oxagen/workspace.json`, which every other command reads to scope itself. It then checks the workspace for a GitHub connection and — interactively — offers to create one so the graph has a source to ground on. `--no-link` skips the whole step.

`init` is idempotent: re-running against an already-linked project reuses the existing link.

## oxagen agent env — bind agents to environments

```bash
oxagen agent env bind <agent> --env <slug> [--primary] [--json]
oxagen agent env unbind <agent> --env <slug> [--json]
oxagen agent env list <agent> [--json]
```

`<agent>` is an agent's public id (`agt_…`), slug, or agent-key. `--env` is an environment slug or `env_` id. The first binding an agent gets becomes its primary; `--primary` atomically demotes the previous one.

## oxagen env — workspace environments

```bash
oxagen env list [--json]
oxagen env get <idOrSlug>
oxagen env create <name> [--slug <slug>] [--description <text>]
oxagen env update <idOrSlug> [--name <n>] [--slug <s>] [--description <t>] [--active|--inactive]
oxagen env rm <idOrSlug>
oxagen env set-default <idOrSlug>
```

Environments are governed configuration records — a named scope that secrets resolve against and agents bind to. The workspace default cannot be deleted.

## oxagen secret — credential vault

```bash
oxagen secret list [--json]
oxagen secret set <key> <value> [--env <slug>] [--no-sensitive]
oxagen secret rm <key> [--env <slug>]
oxagen secret reveal <key> [--env <slug>]
oxagen secret import [--env <slug>] [-f <path>] [--yes]
oxagen secret export [--env <slug>] [-o <path>]
```

The workspace's encrypted credential vault. `list` shows masked metadata only. Values are stored per-key with optional per-environment overrides — `--env` targets one environment's override; omit it for the default value.

`reveal` and `export` return plaintext and are **recorded to the access log**. `import` reads `.env` text from a file or stdin and previews the change unless you pass `--yes`.

## oxagen router — verified-outcome market router

```bash
oxagen router stats [--task-class <c>] [--window <days>] [--min-samples <n>] [--json]
oxagen router preview <prompt> [--files <n>] [--cross-package] [--task-class <c>] [--json]
oxagen router policy get [--json]
oxagen router policy set [--scope <s>] [--mode <m>] [--threshold <n>] [--min-samples <n>] [--window <days>] [--escalate <bool>] [--json]
```

Learned, economic model routing. `stats` reports observed outcomes per (task class, model) and the cheapest model that clears the quality bar in each class. `preview` dry-runs the routing decision for a prompt and changes nothing. `policy set` requires org **Owner** or **Admin** — it changes spend behavior.

## oxagen conversation — export a conversation

```bash
oxagen conversation export <id> [--format md|pdf] [-o <file>] [--json]
```

Exports a conversation's active branch. Markdown goes to stdout or `-o`; PDF is stored privately and the command prints the serve URL.

## oxagen asset — ingest a binary asset

```bash
oxagen asset upload <url> [--kind <kind>] [--filename <name>] [--conversation <id>] [--json]
```

Ingests an asset from a public URL into object storage. With `--conversation`, records it as a private chat attachment linked to that conversation.

## oxagen logs — CLI debug log

```bash
oxagen logs [-n <lines>] [--category <c>] [-f] [--path] [--clear] [--json]
```

Reads the CLI's own log at `~/.oxagen/logs/cli.output`. Every invocation is recorded; set `OXAGEN_CLI_DEBUG=1` for full detail. `--path` prints the log location, `--clear` truncates it, `-f/--follow` tails.

## oxagen telemetry — anonymous usage telemetry

```bash
oxagen telemetry [on|off|status]
```

Anonymous usage telemetry — command names, durations, coarse success/error categories, OS/arch. Never code, prompts, file contents, paths, model slugs, or keys. On by default; `DO_NOT_TRACK=1` also disables it.

## Login and logout

```bash
oxagen login                                                   # browser OAuth + org/workspace picker
oxagen login --token oxk_live_… --org acme --workspace main    # CI / headless
oxagen login --no-browser                                      # print the URL instead of opening it
oxagen logout                                                  # clear the stored session
```
