---
title: Installing the CLI
description: Install the oxagen CLI with the install script, from the monorepo, as a portable single-file bundle, or from npm.
---

Source and JavaScript-bundle installs need **Node.js 20 or newer**. Prebuilt executables include their runtime. Check `node --version` when using a JavaScript install.

There are four ways to get it. Use the install script unless you have a reason not to.

## Install script (recommended)

```bash
curl -fsSL https://cli.oxagen.sh/install.sh | sh
```

The script detects your platform (macOS or Linux, arm64 or x64), downloads the matching prebuilt binary, checks it against its published SHA-256, and writes it to `~/.local/bin`. It never asks for `sudo`. It refuses to install a binary whose checksum file is missing or does not match. If no prebuilt binary exists for your platform yet, it falls back to `npm install -g @oxagen/cli`, which needs Node.js 20 or newer.

A successful run on an Apple Silicon Mac:

```console title="Terminal"
$ curl -fsSL https://cli.oxagen.sh/install.sh | sh
▸ detecting platform · darwin-arm64
▸ fetching oxagen · verifying checksum
✓ install: /Users/you/.local/bin/oxagen
✓ oxagen is on your PATH — run `oxagen` to get started
```

Two environment variables change where it looks and where it writes:

| Variable | Default | What it does |
| --- | --- | --- |
| `OXAGEN_INSTALL_DIR` | `~/.local/bin` | Where the binary is written |
| `OXAGEN_INSTALL_BASE` | `https://cli.oxagen.sh/releases/latest` | Where releases are fetched from |

If `~/.local/bin` is not on your `PATH`, the script prints the line to add to your shell profile. Read the script before you run it.

## From the monorepo

Clone the repo, install dependencies, and run the CLI directly from source:

```bash
git clone https://github.com/macanderson/oxagen.git
cd oxagen
pnpm install

# Run straight from source (TypeScript via tsx):
pnpm --filter @oxagen/cli start --version

# …or compile once and run the built output:
pnpm --filter @oxagen/cli build
node apps/cli/dist/index.js --version
```

To get a short `oxagen` command, alias it in your shell profile (`~/.zshrc`, `~/.bashrc`):

```bash
alias oxagen='pnpm --filter @oxagen/cli start'
# then:  oxagen budget show
```

## Standalone bundle (portable, no install)

For CI runners, ephemeral containers, or an `oxagen` on your `PATH` without a global npm install, build a self-contained single-file bundle. It runs under plain `node` with no workspace resolution and no `npm install` step:

```bash
pnpm --filter @oxagen/cli bundle
# → apps/cli/dist-standalone/oxagen.mjs  (executable, Node 20+)

node apps/cli/dist-standalone/oxagen.mjs --version
```

The bundle is one `.mjs` file. Copy it anywhere and run it, or symlink it onto your `PATH`:

```bash
ln -s "$(pwd)/apps/cli/dist-standalone/oxagen.mjs" /usr/local/bin/oxagen
oxagen --version
```

<Callout type="info">
The bundle has no native dependencies. It needs only Node.js 20 or newer on `PATH`.
</Callout>

## From npm

<Callout type="warn">
**A global npm install can fail.** The published `@oxagen/cli` package still
carries internal workspace dependencies, and its launcher expects `tsx` on your
`PATH`. As a result, `npm i -g @oxagen/cli` may not produce a working `oxagen`
outside the monorepo. Use the **install script** above instead.
</Callout>

`@oxagen/cli` is published to npm:

```bash
npm install -g @oxagen/cli
# or
pnpm add -g @oxagen/cli

oxagen --version
```

## Verify the install

Whichever method you used, confirm the binary works and read the top-level help:

```bash
oxagen --version
oxagen --help
```

`oxagen --help` lists every command group. Append `--help` to any command (for example `oxagen graph search --help`) to see its flags.
