title: Installing the CLI

There are three ways to get the `oxagen` command. Install the Oxagen app unless you need the command without it, on a server or a CI runner for example.

## The Oxagen app (recommended)

The app installs `oxagen` and keeps it current. On first launch it links the command into `~/.local/bin` on macOS and Linux, and onto your user `PATH` through a `.cmd` shim on Windows. It never asks for administrator rights.

<LatestDownloads />

Every version, with a SHA-256 for each file, is listed at [downloads.oxagen.sh](https://downloads.oxagen.sh/). [Oxagen app](/docs/cli/desktop) covers the first launch on each platform, where the command lives, and how updates work.

## A single executable

Each version also publishes `oxagen` as one executable per platform, the same file the app links onto your `PATH`. It carries its own runtime, so it needs no Node.js. A `.sha256` sits beside each file.

| Platform | File |
| --- | --- |
| macOS Apple silicon | `oxagen-aarch64-apple-darwin` |
| macOS Intel | `oxagen-x86_64-apple-darwin` |
| Linux x86_64 | `oxagen-x86_64-unknown-linux-gnu` |
| Windows x64 | `oxagen-x86_64-pc-windows-msvc.exe` |

On macOS or Linux, run the install script:

```bash
curl -fsSL https://docs.oxagen.sh/install.sh | sh
```

The script downloads the file for your platform from `latest/`, checks its SHA-256, and installs it to `~/.local/bin`. It never uses sudo. On Linux arm64, which has no executable yet, it installs from npm instead. To pin a version, run it as `curl -fsSL https://docs.oxagen.sh/install.sh | OXAGEN_INSTALL_BASE=https://downloads.oxagen.sh/desktop/<version> sh`.

To do the same steps by hand, download the file for your platform and its checksum, check it, and install it:

```bash
name=oxagen-aarch64-apple-darwin   # the file for your platform, from the table
curl -fsSLO "https://downloads.oxagen.sh/latest/$name"
curl -fsSLO "https://downloads.oxagen.sh/latest/$name.sha256"
shasum -a 256 -c "$name.sha256"     # on Linux: sha256sum -c "$name.sha256"
mkdir -p ~/.local/bin
install -m 755 "$name" ~/.local/bin/oxagen
```

`latest/` always holds the newest version. To pin one, replace `latest` with `desktop/<version>`, for example `https://downloads.oxagen.sh/desktop/2.2.0/oxagen-aarch64-apple-darwin`. Each release page under [Releases](/docs/releases) links its own files.

On Windows, download `oxagen-x86_64-pc-windows-msvc.exe`, rename it to `oxagen.exe`, and put it in a directory on your `PATH`.

If `~/.local/bin` is not on your `PATH`, add `export PATH="$HOME/.local/bin:$PATH"` to your shell profile.

## From npm

<Callout type="warn">
**npm lags the app.** The `@oxagen/cli` package on npm is an older version than the one the app and the executables ship. Run `npm view @oxagen/cli version` to see which version npm holds. Use the app or the single executable for the current version.
</Callout>

The npm package needs **Node.js 20 or newer**:

```bash
npm install -g @oxagen/cli
oxagen --version
```

## Verify the install

Whichever method you used, confirm the binary works and read the top-level help:

```bash
oxagen --version
oxagen --help
```

`oxagen --help` lists every command group. Append `--help` to any command (for example `oxagen graph search --help`) to see its flags.
