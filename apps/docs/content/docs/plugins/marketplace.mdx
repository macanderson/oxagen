title: Plugin catalog
description: "Browse and install workspace plugins through the capability API or MCP."
---

Use `browse_plugin_catalog` to find a plugin, then `get_catalog_plugin` to inspect its tools and authentication requirements. The former Marketplace screen is not part of the current app.

## Install a plugin

Call `install_plugin` for one plugin or `install_plugins_bulk` for several. Use the input schema returned by your MCP client or the capability contract for the fields. Installation is workspace-scoped.

MCP servers and integrations may need a separate credential before their tools can be used. See [Workspace plugins](/docs/plugins/workspace-plugins).

## Custom servers and registries

Use `register_mcp_server` for a workspace server. Use `add_plugin_registry` to add a discovery source, then browse its catalog. [MCP server registries](/docs/plugins/registries) explains registry URLs and removal.

The current **Tools** page manages tool versions, connection grants, kill switches, and mandates. It does not reproduce the retired Marketplace screens.

## Remove a plugin

Call `uninstall_plugin` in the workspace where it was installed. Review the capability input and role requirements before making the call. Existing audit records remain. See [Plugin governance](/docs/governance/plugins-governance).
