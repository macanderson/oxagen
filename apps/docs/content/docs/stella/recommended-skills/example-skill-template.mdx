## Name

`[skill-name]` — a short, kebab-case name matching the memory filename you'll ship, e.g. `withtenantdb-only`.

## What it does

One or two sentences: the convention, gotcha, or piece of domain knowledge this skill teaches Stella. Be specific — "always use X, never Y, because Z" reads better than a vague description.

## When Stella loads it

Like every file in `.stella/memories/`, this skill has no separate registration step. Drop the file into `.stella/memories/[skill-name].md` in a repository and Stella loads it into the system prompt at the start of the **next** session — memories load once per session by design, so a save mid-session takes effect next time ([Subcommands & flags → Workspace state](/docs/stella/commands#workspace-state)).

## SKILL.md content

The exact markdown to copy into `.stella/memories/[skill-name].md`:

```markdown
# [Skill name]

[The lesson, convention, or workflow, written the way you'd want Stella to
read it back to you. Keep it concrete and specific — this text becomes part
of the system prompt on every turn, so every sentence should earn its
tokens.]

- [A specific rule or step]
- [Another specific rule or step]
```

## Install / copy instructions

```bash
mkdir -p .stella/memories
curl -fsSL https://raw.githubusercontent.com/[org]/[repo]/main/skills/[skill-name].md \
  -o .stella/memories/[skill-name].md
```

Or, without a hosted copy, paste the fenced block above directly into a new `.stella/memories/[skill-name].md` file.
