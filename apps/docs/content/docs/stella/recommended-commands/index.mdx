Stella's REPL slash commands (`/goal`, `/files`, `/models`, …) are fixed — the binary doesn't support user-defined ones. What we call a **custom command** in this section is a shell-level convention instead: a well-crafted prompt for `stella run` or `stella goal`, wrapped in a shell alias or function so invoking it feels like a first-class command even though Stella itself never sees anything beyond the final prompt string.

The entries in this section are the author's own setups: published as open source, run in real repositories, and kept here because the underlying prompt has earned its keep across many runs rather than being written for the docs. Each one documents a single command you can copy into your shell profile or a project's scripts.

## Layout of a command entry

Every command entry in this section follows the same structure — see [Command entry template](/docs/stella/recommended-commands/example-command-template) for a page you can copy wholesale:

| Section | Contents |
|---|---|
| Name | The alias or function name you'll invoke it by |
| What it does | One or two sentences on the task it runs |
| The command | The full shell alias/function definition, in a fenced block, ready to copy |
| Usage examples | One or more example invocations and what to expect |
| Works well with | A cross-link to any skill or other command in this section it pairs with |

## Adding a new command

Copy [`example-command-template.mdx`](/docs/stella/recommended-commands/example-command-template), fill in each section, add the new file's slug to `content/docs/stella/recommended-commands/meta.json`, and open a PR.
