Oxagen, the Oxagen app, `tacho`, and the `oxagen` CLI share one version number. Each page below is one release: a short summary of the changes that matter to an operator, written from the diff and read once by a person before it ships, then the downloads for that version on every platform.

The current version is always at [downloads.oxagen.sh](https://downloads.oxagen.sh/). Installed apps take the new version from the in-app updater; the CLIs inside the app move with it.
