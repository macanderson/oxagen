Give an agent an identity, then set its authority, budget, tools, and skills in its mandate. Oxagen checks actions routed through its control plane and records the result.

## Create your organization and workspace

1. Open [app.oxagen.sh](https://app.oxagen.sh) and choose **Sign up**.
2. Enter your name, email, and password. Follow the verification email when the deployment requires it.
3. Name your organization and its first workspace on the **New organization** screen.
4. Review their slugs and create the organization.

The first workspace opens at `/{org}/{workspace}`. This is Fleet. Local development skips email verification. See [Local development](/docs/configuration/local-development).

## Find the right page

| Page | What you manage |
|---|---|
| Fleet, `/{org}/{workspace}` | Recorded agent activity and work awaiting attention |
| Agents | Agent identities and enrollment |
| A run | The recorded steps, decisions, and cost for that run |
| A mandate | The authority and equipment assigned to an agent |
| Tools | Tool registry, connections, kill switches, and the mandate ledger |
| Steering | Instructions and rules |
| Spend | Recorded usage and cost |
| Skills | Skills assigned to agents |
| Organization, `/{org}` | Workspaces and membership |
| Organization → Roles | Roles and their permissions |
| Organization → API keys | Keys scoped to a workspace |
| Organization → Audit | Security event records |
| Organization → Billing | Subscription and credits |
| Organization → Model funding | Who pays for model calls |

## Install the Oxagen app

Install the app on the machine that runs the agent. On first launch it links the `oxagen` and `tacho` commands onto your PATH, and the enrollment command below needs them.

## Register and enroll an agent

Open **Agents** and follow the registration flow. Run the enrollment command it gives you on the machine that runs the agent:

```bash
oxagen agent enroll --token <one-time-enrollment-token> --harness claude-code
oxagen agent status
```

The token identifies the organization, workspace, and registered agent. It expires after 30 minutes and can be used once. Enrollment installs the collector and the selected harness hooks. See [Wrap an agent](/docs/cli/wrap-an-agent) for the recording boundary and custom agents.

Run a task in the wrapped harness. Open Fleet to inspect the record that arrived. Observe mode records activity without enforcing it. Hook checks depend on the installed wrapper, and calls outside the routed boundary are not governed by Oxagen.

## Use the CLI, API, or MCP

Run `oxagen login` for a browser-authorized CLI credential. For a script or MCP client, create a workspace-scoped key at **Organization → API keys** and copy it when shown.

[API authentication](/docs/api/authentication) explains the different key purposes. [The API overview](/docs/api/overview) provides a first request. [Connecting to MCP](/docs/mcp/connecting) provides client configuration.
