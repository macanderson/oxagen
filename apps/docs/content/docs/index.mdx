Give each agent an identity and a mandate: its authority, budget, tools, skills, and rules. Oxagen is workforce management for autonomous agents. It checks actions routed through the control plane and keeps the record. Your harness runs the agent.

## Start with one agent

[Create an organization and workspace](/docs/getting-started), register an agent, and enroll the machine that runs it. Open Fleet to inspect the recorded work. [Wrap an agent](/docs/cli/wrap-an-agent) explains what hooks record and where enforcement applies.

## Set its authority and equipment

[Roles](/docs/governance/rbac) determine which capabilities a principal may call. [Agent roles](/docs/governance/agent-roles) bound the agent's requests. Use the mandate, Tools, Steering, and Skills pages to manage its equipment and instructions.

For mediated connections, Oxagen holds the downstream credential and uses it on the agent's behalf. The agent's own authentication is separate. Observe mode records activity without enforcing it.

## Inspect cost and evidence

[Spend budgets](/docs/cli/budget) put period limits on governed consumption. [Billing](/docs/billing) explains credits and model funding. [Audit logging](/docs/security/audit-logging) describes the security record and its limits.

[Workspace memory](/docs/agent/memory) and the [knowledge graph](/docs/knowledge) supply scoped context. Agents must request that context through the supported capabilities.

## Choose an interface

- [CLI](/docs/cli): inspect runs, budgets, memory, environments, and secrets.
- [REST API](/docs/api/overview): call versioned capability routes.
- [MCP](/docs/mcp/overview): expose the capabilities declared for MCP to a client.
- [Architecture atlas](/docs/architecture): inspect the generated engineering map.

A contract declares which surfaces expose a capability. Those surfaces share the `invoke()` boundary for authorization, billing, entitlement, and audit. See [Capabilities](/docs/api/capabilities) for the contract and route conventions.
