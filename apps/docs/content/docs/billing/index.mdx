Open **Organization → Billing** to manage subscription and credits. Open a workspace's **Spend** page to inspect recorded usage and cost.

## Credits and model funding

Governed actions and platform-funded model usage debit credits. The credit ledger records balance changes, while ClickHouse records usage analytics. Those are separate stores with separate write paths.

An organization can supply its own model credential through **Model funding**. Tokens billed by that provider still appear in usage records but do not incur Oxagen's token charge. Governed-action charges still apply. See [Model funding](/docs/governance/byok-and-models).

## Statements

Download a statement for a week, month, quarter, year or custom period from **Statements** on the Billing page, or with `oxagen billing statement`. It lists every billed governed action and reconciles against your invoices. See [Billing statements](/docs/billing/statements).

## Usage breakdown

Use `get_usage_breakdown` to query usage by model, surface, workspace, capability, or principal. Inspect the attribution and whether a figure was measured, reported, or estimated before comparing runs from different harnesses.

## Spend budgets

Read the current organization and workspace ceilings:

```bash
oxagen budget show
```

Set a period ceiling as an organization Owner, Admin, or Billing manager:

```bash
oxagen budget set --scope workspace --period monthly --limit 500
```

Admission checks deny further governed consumption once the recorded limit is reached. A check before a call or turn is not a guarantee that concurrent work cannot cross the limit. [Spend budgets](/docs/cli/budget) documents the accounting periods and threshold states.

Personal per-turn settings are separate from these period ceilings. Inspect the effective budget and funding source for the path you are using.
