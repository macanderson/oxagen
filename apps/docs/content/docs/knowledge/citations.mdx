---

Inspect which workspace memories and graph nodes were cited with `oxagen memory citations` or `get_citation_stats`. The current app has no Citations dashboard.

## What a citation records

A citation links a run to the memory or graph node it cited, and carries two judgments made at cite time:

| Axis | Values | Meaning |
|---|---|---|
| **Influence** | `DECISIVE` → `CONTRIBUTING` → `CONSIDERED` → `IGNORED` | How much the cited knowledge shaped the output. `DECISIVE` and `CONTRIBUTING` count as useful. `CONSIDERED` and `IGNORED` mean the agent recalled it, but it did not change the answer. |
| **Compliance** | `COMPLIED` / `DISCRETION` / `VIOLATION` / `NA` | For RULE and FACT memories: whether the agent followed the rule. `VIOLATION` means the agent acted against a promoted rule. |

Citations accrue on their own, and you instrument nothing. A recall made while answering records a `CONSIDERED` citation (this is the "citation pressure" that surfaces promotion candidates). An `@`-mentioned node records a `DECISIVE` one. An agent can also cite explicitly, with a full influence and compliance judgment.

## Read the results

The statistics include influence and compliance breakdowns, daily totals, most-cited and least-useful memories, violated rules, and cited nodes. These are recorded judgments about context use. They do not prove that an agent complied with every instruction.

Review candidates with `oxagen memory candidates`, then promote, demote, or dismiss them with the [memory commands](/docs/cli/memory).

## Programmatic access

The `get_citation_stats` capability provides these statistics:

```bash
# API
curl -X POST "https://api.oxagen.sh/v1/{org_slug}/{workspace_slug}/agent/memory/citations/stats" \
  -H "Authorization: Bearer $OXAGEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"days": 30, "limit": 10}'

# CLI
oxagen memory citations --days 30 --limit 10
```

`days` (1 to 365, default 30) sets the window. `limit` (1 to 50, default 10) caps each top-N list. The MCP tool `get_citation_stats` takes the same input, so an agent can read its own citation quality.
