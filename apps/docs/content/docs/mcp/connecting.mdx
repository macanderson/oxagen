## Prerequisites

You need an Oxagen API key. Create one at **Organization → Developer → Tokens**. The key acts with the role of the person who created it, so create it from an account whose role covers the tools you want to call.

The MCP server endpoint is:

```
https://mcp.oxagen.sh/mcp
```

Transport: **streamable HTTP** (the current MCP protocol standard).

## Unified install page

The fastest path for any client is the unified install page at **Organization → Developer → MCP**. It writes a copy-ready snippet for every supported client, filled in with your API key.

## Manual configuration by client

### Claude Code

Register the server from a terminal. The URL is a positional argument:

```bash
claude mcp add --transport http oxagen https://mcp.oxagen.sh/mcp \
  --header "Authorization: Bearer $OXAGEN_API_KEY"
```

Add `--scope project` to write the entry to `.mcp.json` at the repository root, so everyone who clones the repo gets the server. That file looks like this:

```json title=".mcp.json"
{
  "mcpServers": {
    "oxagen": {
      "type": "http",
      "url": "https://mcp.oxagen.sh/mcp",
      "headers": {
        "Authorization": "Bearer ${OXAGEN_API_KEY}"
      }
    }
  }
}
```

Run `claude mcp list` to confirm the server connects.

### Claude Desktop

Claude Desktop's config file starts only local (stdio) servers, and its remote connectors sign in with OAuth, which the Oxagen MCP server does not use. Bridge to the HTTP endpoint with [`mcp-remote`](https://www.npmjs.com/package/mcp-remote), which needs Node.js on your machine. Add this to `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) or `%APPDATA%\Claude\claude_desktop_config.json` (Windows):

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "oxagen": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://mcp.oxagen.sh/mcp", "--header", "Authorization:${OXAGEN_AUTH_HEADER}"],
      "env": {
        "OXAGEN_AUTH_HEADER": "Bearer ox_…"
      }
    }
  }
}
```

The header value goes through `env` because some launchers split an argument that contains a space. Restart Claude Desktop after saving.

### Codex

```bash
export OXAGEN_API_KEY=ox_…
codex mcp add oxagen --url https://mcp.oxagen.sh/mcp --bearer-token-env-var OXAGEN_API_KEY
codex mcp list
```

This writes the entry to `~/.codex/config.toml`. Codex reads the key from `OXAGEN_API_KEY` when it connects, so the key never lands in the file:

```toml title="~/.codex/config.toml"
[mcp_servers.oxagen]
url = "https://mcp.oxagen.sh/mcp"
bearer_token_env_var = "OXAGEN_API_KEY"
```

### Programmatic (Node.js / TypeScript)

```typescript
import { Client } from "@modelcontextprotocol/sdk/client/index.js";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";

const transport = new StreamableHTTPClientTransport(
  new URL("https://mcp.oxagen.sh/mcp"),
  {
    headers: {
      Authorization: `Bearer ${process.env.OXAGEN_API_KEY}`,
    },
  }
);

const client = new Client(
  { name: "my-app", version: "1.0.0" },
  { capabilities: {} }
);

await client.connect(transport);

// List available tools
const tools = await client.listTools();

// Call a tool
const result = await client.callTool({
  name: "recall_memory",
  arguments: { query: "quarterly review meeting notes" }
});
```

A tool has the name of the capability behind it, with no translation step: verb-first snake_case, such as `recall_memory` or `list_agent_tools`. See [MCP tools](/docs/mcp/tools) for the list.

## Scope and isolation

Every connection to the MCP server runs in the org and workspace the API key belongs to. The server routes each tool call to that tenant. A caller cannot reach another org's data through the connection, even with that org's resource IDs.

## Verifying the connection

After connecting, call the `get_install_instructions` tool to get client-specific installation instructions for your workspace. The `client` field is required:

```json
{
  "name": "get_install_instructions",
  "arguments": { "client": "claude-code" }
}
```

Supported `client` values: `claude-code`, `cursor`, `claude-desktop`, `codex`, `vscode`. The tool returns copy-ready configuration steps for that client and the connected workspace.

## Troubleshooting

**401 Unauthorized:** The API key is missing, invalid, or revoked. Check the key at **Organization → Developer → Tokens**.

**Tool call denied:** On an Enterprise organization, the person who created the key has no role grant for that capability, or the grant routes the call to a person for approval. Check that person's role under **Governance → Policies**, and see [RBAC and roles](/docs/governance/rbac). Oxagen records each denial as a `capability.invoke_denied` event in **Organization → Security → Audit**.

**Tool not in the list:** The server does not filter the tool list per key. A rule answers each call when the call is made. A tool missing from the list is not exposed on the MCP surface. See [MCP tools](/docs/mcp/tools).

**Connection drops during a long tool call:** A proxy between your client and the server may close a long-held connection. Long-running capabilities, such as starting a background task, return a task ID at once, and Inngest runs the work in the background.
