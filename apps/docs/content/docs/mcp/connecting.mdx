## Prerequisites

You need an API key. Create one at **Organization → Developer → Tokens**. The key acts with the access of the user who created it, so create it from an account whose role covers the tools you want to use.

The MCP server endpoint is:

```
https://mcp.oxagen.sh/mcp
```

Transport: **streamable HTTP** (the current MCP protocol standard).

## Unified install page

The fastest path for any client is the unified install page at **Organization → Developer → MCP**. It generates ready-to-copy configuration snippets pre-filled with your API key for every supported client.

## Manual configuration by client

### Claude Code

Register the server from a terminal. The URL is a positional argument:

```bash
claude mcp add --transport http oxagen https://mcp.oxagen.sh/mcp \
  --header "Authorization: Bearer $OXAGEN_API_KEY"
```

Add `--scope project` to write the entry to `.mcp.json` at the repository root, so everyone who clones the repo gets the server. That file looks like this:

```json title=".mcp.json"
{
  "mcpServers": {
    "oxagen": {
      "type": "http",
      "url": "https://mcp.oxagen.sh/mcp",
      "headers": {
        "Authorization": "Bearer ${OXAGEN_API_KEY}"
      }
    }
  }
}
```

Run `claude mcp list` to confirm the server connects.

### Claude Desktop

Claude Desktop's config file only starts local (stdio) servers, and its remote connectors sign in with OAuth, which the Oxagen MCP server does not use. Bridge to the HTTP endpoint with [`mcp-remote`](https://www.npmjs.com/package/mcp-remote), which needs Node.js on your machine. Add to `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) or `%APPDATA%\Claude\claude_desktop_config.json` (Windows):

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "oxagen": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://mcp.oxagen.sh/mcp", "--header", "Authorization:${OXAGEN_AUTH_HEADER}"],
      "env": {
        "OXAGEN_AUTH_HEADER": "Bearer ox_…"
      }
    }
  }
}
```

The header value is passed through `env` because some launchers split an argument that contains a space. Restart Claude Desktop after saving.

### Codex

```bash
export OXAGEN_API_KEY=ox_…
codex mcp add oxagen --url https://mcp.oxagen.sh/mcp --bearer-token-env-var OXAGEN_API_KEY
codex mcp list
```

This writes the entry to `~/.codex/config.toml`. Codex reads the key from `OXAGEN_API_KEY` when it connects, so the key never lands in the file:

```toml title="~/.codex/config.toml"
[mcp_servers.oxagen]
url = "https://mcp.oxagen.sh/mcp"
bearer_token_env_var = "OXAGEN_API_KEY"
```

### Programmatic (Node.js / TypeScript)

```typescript
import { Client } from "@modelcontextprotocol/sdk/client/index.js";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";

const transport = new StreamableHTTPClientTransport(
  new URL("https://mcp.oxagen.sh/mcp"),
  {
    headers: {
      Authorization: `Bearer ${process.env.OXAGEN_API_KEY}`,
    },
  }
);

const client = new Client(
  { name: "my-app", version: "1.0.0" },
  { capabilities: {} }
);

await client.connect(transport);

// List available tools
const tools = await client.listTools();

// Call a tool
const result = await client.callTool({
  name: "recall_memory",
  arguments: { query: "quarterly review meeting notes" }
});
```

A tool is named after the capability behind it, with no translation step — verb-first snake_case, such as `recall_memory` or `list_agent_tools`. See [MCP tools](/docs/mcp/tools) for the list.

## Scope and isolation

Every MCP session is scoped to the org and workspace associated with the API key. The server automatically routes all tool calls to the correct tenant context. You cannot access another org's data from the same session, even if you know the resource IDs.

## Verifying the connection

After connecting, call the `get_install_instructions` tool to retrieve client-specific installation instructions for your workspace. The `client` field is required:

```json
{
  "name": "get_install_instructions",
  "arguments": { "client": "claude-code" }
}
```

Supported `client` values: `claude-code`, `cursor`, `claude-desktop`, `codex`, `vscode`. The tool returns ready-to-copy configuration steps tailored to the specified client and the connected workspace.

## Troubleshooting

**401 Unauthorized:** The API key is missing, invalid, or has been revoked. Check the key at **Organization → Developer → Tokens**.

**Tool call refused:** On an Enterprise organization, the user who created the key lacks a role grant for that capability, or the grant requires approval. Check the key creator's role under **Governance → Policies**. Refusals are recorded as `capability.invoke_denied` events in **Organization → Security → Audit**.

**Tool not in list:** The tool list is not filtered per key — authorization happens when a tool is called. A missing tool is not exposed on the MCP surface; see [MCP tools](/docs/mcp/tools).

**Connection drops after 25 seconds:** Your client may be on a platform with a short serverless function timeout. The MCP server is deployed on Vercel Functions. Long-running tool calls (background task start, video generation) are designed to return immediately with a task ID — the actual work runs asynchronously via Inngest.
