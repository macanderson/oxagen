The trust problem

Three ways an agent
lets you down.

01

✗It says it is done.

Nothing checked. Nobody looked. You find out in production, on a Friday.

02

✗You cannot see what it did.

No trail. No cost. No way to tell a good run from a lucky one.

03

✗Your code went out.

Straight to someone else's cloud. You cannot say where it slept.

Every one of these is the same problem wearing a different hat. You have no proof.

01 / Receipts

Done means
a test passed.

Stella does not grade its own homework. A second model writes a test that fails on the old code. The worker fixes the code. The test flips to green. That flip is the receipt.

  1. 01
    Write the failing testA different model writes it. Not the one doing the work.
  2. 02
    Do the workThe worker cannot touch the test. If it does, the receipt is void.
  3. 03
    Watch the flipRed to green, recorded. No flip, no done. It is that simple.
