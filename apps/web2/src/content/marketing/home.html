The agent — in your terminal

An agent that already knows your codebase

Type what you want done. The agent reads your code, makes the edits, runs the checks, and shows its work — grounded in your team's shared map, not just the files in front of it.

One command, done

Ask in plain English. It plans, edits, verifies, and hands you the diff — in an interactive session or a single shot.

$ oxagen "make the export async"
✎ src/export/index.ts +12 −4
✔ checks passed — diff ready for review

Dispatch a fleet

One goal becomes many tasks. Several agents work in parallel, each safely in its own copy of the repo, and report back as one.

◆ 4 tasks · 4 workers · isolated worktrees
worker/1 schema done · worker/2 routes done
worker/3 webhooks running · worker/4 tests running

Private by default

Run the agent on a model that lives on your own machine. Works offline, no key required, nothing leaves the laptop.

The platform — mission control

Mission control for every agent you run

The same map and rules power the web app, the API, and your editor's tools — so the whole team and every agent work from one governed place.

Approved before it runs

Decide who and what can take each action. Anything outside the rules simply doesn't run — no exceptions to chase later.

Measured as it runs

Every model call and tool action is counted, so you always know what your agents cost — down to the team, the task, and the customer you bill.

On the record after it runs

A tamper-evident log of every action, ready for your next security review — instead of a scramble before it.

One shared map

Connect your sources once. Answers come back grounded in your own data, with citations you can open — in the app, over the API, or in your tools.

How it works

Three moves. No rewiring.

STEP 01

Connect

Point Oxagen at your code and the tools your team already uses. It builds one connected, living map of how everything relates.

STEP 02

Ask

Work with the agent in your terminal or in the app. It answers from your map — right the first time, with sources you can check.

STEP 03

Govern

Set the rules once. Every action any agent takes is approved up front, measured as it happens, and kept on the record.
