# 🌌 Oxagen v0.1.0 — *First Light*

> The graph is lit. The agents have a place to stand. This is the foundation
> everything else gets built on — one capability surface, four honest stores,
> and an audit trail you can actually follow back to the evidence.

## ✦ The constellation that ships in this release

```
            ┌─ packages/oxagen ─┐         one contract registry, declared once,
   API ─────┤  capability core  ├───── MCP   exposed identically to API · MCP · app
            └─────────┬─────────┘         ( drift fails the verification gate )
                      │
        ┌─────────────┼──────────────┬───────────────┐
     Postgres       Neo4j        ClickHouse        file store
   (transactional) (the graph)  (append-only)    (artifacts)
```

### 🧠 One brain, four memories — the four-store data model
Transactional truth in **Postgres**, relationships in **Neo4j**, append-only
runtime telemetry in **ClickHouse**, blobs on disk. Each store holds only the
slice of state it's best at; the boundaries are enforced, not suggested.

### 🛂 IAM that says *no* by default
Per-capability authorization, **deny-by-default**. Real role membership via
`principal_role_assignments` (no more "everyone is every role"), **JIT roles**
that actually expire (`expires_at` is now honored), workspace-scoped grants that
don't leak org-wide, and an authz check that **fails closed** when the resolver
throws.

### 🔐 Auth you can trust with tokens
Better Auth on the canonical `auth.users` row, secure cookies, env-driven
trusted origins, and **OAuth token envelope encryption via AWS KMS** — production
literally cannot boot without it (and the build no longer pretends it's a
build-time concern).

### 💳 Credits that can't double-spend
A credit ledger where **1 credit = 1¢**, grants made **atomic** by a partial
unique index (`ON CONFLICT DO NOTHING` finally has something to conflict on),
use-it-or-lose-it subscription credits, 1-year packs, and Stripe sync.

### 🤖 An agent runtime with guardrails
Tool dispatch through a single `invoke()` chokepoint (metering + IAM + audit),
**subagent fanout with a depth guard that actually increments** (no more
infinite recursion), approvals, and generative UI streamed as structured data →
typed React components (no RSC).

### 📊 Telemetry + a tamper-evident audit trail
Per-turn token usage in ClickHouse, and a **7-year, hash-chained IAM audit
trail** — every capability invocation traceable to org, workspace, user, run,
model, and the source data that justified it.

## 🛠️ Hardening — audit remediation OXA-1497–1510
This release closes the foundations audit: KMS-required-in-prod guard, JIT
expiry, fanout depth fix, atomic credit idempotency, ClickHouse TTL correctness,
schema `text→boolean` migration safety, chat-history IDOR scoping, and assistant
replies that finally **persist across refreshes**.
