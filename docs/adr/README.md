- [ADR-088](./ADR-088-a-credential-follows-the-service-that-reads-it.md) — A credential is registered for every service that reads it: `apps/app` reaches every capability in-process through the kernel seam, so the GitHub App's client id, slug, state secret, client secret, app id and private key — and the ingestion-crypto material that opens a stored OAuth token — name `app` as well as `api`. - [ADR-092](./ADR-092-an-abandoned-assistant-turn-is-owned-not-cancelled.md): A turn the person walks away from is owned to completion, not cancelled. Routing by the workspace a turn was asked in has no race. Stopping a turn on purpose stays with #2953.

- [ADR-099](./ADR-099-a-workspace-is-born-with-its-main-repository.md) — A workspace is born with its main repository, and a repository is main for at most one workspace: `create_workspace` requires `mainRepo` and writes the workspace, its GitHub connection, the version-1 binding and its `role = 'main'` head in one transaction, so a workspace without a main repo is never written. The installation is the one the org's stored GitHub authorization reaches on the repository's owner account, never a caller-supplied id, because a chosen id would let one tenant mint tokens for another account's installation. The global unique index `repository_binding_heads_main_repository_uq` is the race backstop; `link_repository` refuses another workspace's main (`main_repo_claimed`) because §10.1 opens Context PRs on the linked repository; `unlink_repository` deletes only the head and keeps binding versions as evidence; the org's first workspace from `create_org` is the spec's one exception, provisional for 14 days. - [ADR-100](./ADR-100-frame-bodies-are-captured-by-default-redacted-at-the-host-capped-and-governed-by-retention.md) — Every recorder captures the content its frames are about, with no flag to turn on: the hooks, the model proxy, the MCP gateway and the in-app assistant. Redaction runs where the bytes are produced and the body digest names the redacted bytes, never the bytes that arrived. One MiB per body and four per batch; past the cap there is no body and the frame keeps its digest, because truncated bytes digest to a value naming nothing that existed. `retention.mode: digest_only` keeps the chain and ships none of it. The event registry now names which events complete a step, so the seal, the transcript, the Runs page and the cost rollup stop each holding their own list of two names the only producer in the tree does not write.
- [ADR-101](./ADR-101-four-first-class-harnesses.md) — Claude Code, Codex, Cursor and Stella are the four wrapped harnesses, and none of them is the default.
