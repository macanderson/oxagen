A caller that read the mandate, merged its edit and posted the whole record back held a snapshot nobody locked, so two operators changing different bounds on one mandate could each write a complete record and the later write would restore the bound the earlier one lowered. Replacement stays exactly as it was, because it is the only way to delete a bound and it is the right primitive for a caller that holds the record. The two are mutually exclusive; the contract refuses both.
- [ADR-103](./ADR-103-the-price-book-records-its-own-initialization.md) — The price book records its own initialization in `cost.price_book_initializations`: the instant, and the catalogs that answered completely at it. The cold-start floor, which backdates a key the book has never priced to an instant before every frame, must fire only for a source that was down at initialization, and that set cannot be read back off `price_entries`, because precedence drops every row of a catalog whose models all lost to a higher-precedence source. Reading it off the rows floored such a catalog's first unique model and let the next rollup change costs on runs that had already settled. Per install, no RLS, written in the same transaction as the book's first rows. A missing record means the sources are unknown, and unknown floors nothing, because an unpriced frame can be repaired and a repriced settled run cannot.
- [ADR-104](./ADR-104-a-harness-label-round-trips-whatever-it-holds.md) — `list_skills`' harness aggregation moves from a newline-delimited `string_agg` to `jsonb_agg`, so a harness label round-trips byte-for-byte no matter what it contains, instead of splitting a label with a newline into invented harnesses or failing the whole read over one session's empty label. - [ADR-105](./ADR-105-an-archived-workspace-accepts-no-machine-credential.md) — An API key bound to an archived workspace no longer authenticates, and archiving revokes nothing. `resolveApiKey` reads the workspace it resolved and refuses with `workspace_archived`, so the rule holds on every surface that resolves a key and applies to keys stranded by archivals that happened before it, with no migration. - [ADR-106](./ADR-106-retirement-revokes-what-it-scoped.md) — `retire_agent` now also revokes every mandate still `active` or `draft` against the agent's principal, in the same transaction that archives the agent, suspends the principal, and revokes credentials and hosts, instead of leaving a mandate that reads `active` bound to a principal that can never draw on it. - [ADR-108](./ADR-108-a-mandate-limit-carries-its-own-measure-kind.md): A mandate limit's `kind` (money or count) is worked out once, at write time, by `assertToolsDeclareMeasures` from the tool's declared measure type, and stored on the limit and on the read-side authority, instead of every downstream reader guessing money-or-count from whether `currencyOrUnit` looks like an ISO 4217 code. The guess was wrong whenever a tool legitimately declared a count denominated in a currency code, printing a whole-unit count of 50 as $0.00 while the gate correctly enforced 50 counted units.
