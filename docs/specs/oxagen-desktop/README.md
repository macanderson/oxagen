# Oxagen Desktop

`spec.html` is the specification of the desktop app (`apps/desktop`): the
installer for macOS, Linux and Windows that wraps Claude Code and Codex under
Tacho, signs a machine in to an organization, and manages the workspace the
host reports to. It is a self-contained page in the house brand; open it in
a browser, or read the shared copy:

- Artifact (rev 1, 2026-09-13): https://claude.ai/code/artifact/41070634-87a0-4537-b663-031b6b86297e

Related specs: `docs/specs/tacho/spec.md` (the wrapper), `docs/specs/tacho/plan.md`.
When the app changes, edit `spec.html` here and republish the artifact from
it; the repo copy is the source.
