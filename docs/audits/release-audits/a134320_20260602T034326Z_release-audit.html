Blockers (FAILs, ranked by severity)

  • SEV-1  Tenant data-isolation gap (Check 7). No Postgres RLS anywhere. ~11 child/pivot tables have no org_id and no centralized query-time filter — scope rides only on FK joins: execution.execution_steps, execution.tool_calls, agent.subagent_runs (queried by fanoutId only — subagent.ts:109, agent.execute-subagent.ts:55), agent.tool_versions, agent.tool_assignments, workflow.playbook_step_assignments, workflow.prompt_template_versions, event.workflow_triggers, integration.connection_sync_jobs, evaluation.eval_runs, billing.invoice_line_items. Mitigant: several of these are also orphaned (no CRUD — see Check 4), so the leak is latent, not live for those. Live concern is execution_steps, tool_calls, subagent_runs, invoice_line_items. Fix = migrations + scoped repository/Drizzle middleware → touches migrations, needs sign-off.
  • SEV-1  IAM enforcement off + audit emitter unwired (Check 6). setSecurityEventEmitter is called only in tests — no surface (apps/api, apps/mcp, apps/app) writes capability allow/deny to Postgres security.security_events, breaking the SOC 2 CC6/CC7 audit trail. IAM_ENFORCEMENT_ENABLED transforms undefined→false (packages/config/src/env.ts:84), so every deny is advisory in any env where the flag is unset. Security-sensitive — needs decision before prod.
  • SEV-2  E2e critical paths uncovered + e2e absent from CI (Checks 18, 19). Tenant-isolation, billing, and MCP/agent-parity specs assert only the unauthenticated redirect. The only substantive spec (agent-runtime-flow.spec.ts, 21 assertions) needs live DB+Neo4j and was dropped from CI in ee2633c. No e2e runs anywhere.
  • SEV-2  Build-cache poisoning (Check 15). next build reads BETTER_AUTH_SECRET, DATABASE_URL, BETTER_AUTH_URL, OAuth client IDs at module scope (packages/auth/src/auth.ts:20-26) but turbo.json build.env declares none of them — a build cached with one secret set can be served with another. Safe to fix.
  • SEV-2  Coverage gate doesn't exist + untested modules (Check 13). No coverage.thresholds in any vitest config. packages/config & packages/ui ship real tests that turbo never runs (no test:unit script). apps/admin·cli·website·mcp have zero tests (mcp = 22 tool handlers untested).
  • SEV-3  Headless parity gap (Check 14). agent.approval.resolve & agent.plan.approve have no MCP tool — MCP-driven workflows cannot clear approval/plan gates. Manifest records them as intentional, but it violates the "no drift across surfaces" prime directive. Fix needs Postgres LISTEN wiring for the approval wait.
  • SEV-3  Dead schema (Check 4). 10 orphaned tables (promptTemplates, promptTemplateVersions, contentGenerations, connectionSyncJobs, graphProviders, routingRules, orgSlugHistory, workspaceSlugHistory, evals, evalRuns). Decision required per table: wire CRUD or drop in a migration.
  • SEV-4  Stale docs (Check 20). Wrong @ai-sdk/react claim, nonexistent /plugins dir, missing admin/docs apps, wrong proxy runtime claim. Safe to fix.
