# Agent Coding Policy

Binding rules for any coding agent operating in this monorepo. This file is law. When a request conflicts with a rule here, stop and surface the conflict instead of drifting. Do not weaken a rule to make a task easier.

Each section lives in its own file. Read all of them; they are one body of law split for navigation, not priority. The foundational constraints, prime directives, and Oxagen project-specific rules (including data storage and SQL conventions) are combined in `0-prime-directives.md`.
