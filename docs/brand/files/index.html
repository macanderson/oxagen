Brand Guidelines · v1.0

The brain of the
agentic era.

Oxagen is context infrastructure for enterprise AI agents — a managed ontology that agents query for memory, reasoning, and shared truth. This is the brand system: marks, color, type, and components.

01 — Identity

The mark & logotype

The cored node O reads as the letter O and a graph node at once: a ring, a filled center, three radiating edges. The logotype is set in Monaspace Krypton, lowercase. Both flip with the theme.

Logotype flavors

Four Monaspace cuts of the wordmark. Krypton is the default — its mechanical geometry rhymes with the mark.

Krypton · default · mechanical
Neon · humanist · clean
Argon · geometric · friendly
Xenon · slab serif · authority
Do

Keep clear space equal to the core diameter. Use the gradient mark on ink for hero moments. Use adaptive monochrome everywhere else.

Don't

Recolor individual elements, rotate or stretch the mark, set the wordmark in a non-Monaspace font, or place black on dark.

03 — Typography

The Monaspace system

One superfamily, four roles. Every cut shares the same metrics, so they mix without friction — the whole identity reads as one engineered voice.

08 — Implementation

Copy-paste theme

The full token set lives in css/oxagen-theme.css (Tailwind v4 + shadcn, OKLCH) and css/oxagen-fonts.css. Drop both into your app, import after Tailwind, and the whole system themes itself. Retune the brand by editing the :root and .dark blocks.

/* app/globals.css */
@import "tailwindcss";
@import "./css/oxagen-fonts.css";
@import "./css/oxagen-theme.css";

/* fonts map to roles automatically: */
/*   font-display → Krypton  ·  font-heading → Xenon */
/*   font-sans    → Neon     ·  font-mono    → Argon */

<button class="bg-primary text-primary-foreground">
