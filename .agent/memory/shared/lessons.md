# Shared lessons

- [2026-07-21] In this workspace, pass Vitest file filters as positional arguments through `pnpm --dir <package> exec vitest run <file>`; `test:unit -- <file>` can forward a literal separator and unintentionally run the full package suite. (source: codex/reflections/2026-07-21-stella-telemetry-intake-task-5.md, agent: codex)
- [2026-07-21] An integration hook that skips after a service ping must have a timeout longer than the client's transport timeout, or an unavailable dependency turns the intended skip into a hook failure. (source: codex/reflections/2026-07-21-stella-telemetry-intake-task-5.md, agent: codex)
- [2026-07-21] Separate blocking `before_finalize` work from durable post-commit `after_turn` observation; commit terminal state and outbox obligations atomically. (source: root/reflections/2026-07-21-toml-artifacts-lifecycle-design.md, agent: root)
- [2026-07-21] Foreign tool permissions can be one-to-many classes; map them only through exact audited target sets and intersect with live tools, entitlements, and IAM. (source: root/reflections/2026-07-21-toml-artifacts-lifecycle-design.md, agent: root)
- [2026-09-07] When a UI affordance enforces an invariant, verify the SERVER contract that backs it still exists; after a subsystem excision the affordance often outlives its binding and becomes a pure liability (here a per-conversation agent lock survived the deletion of the durable code binding it mirrored). (source: debugger/reflections/2026-09-07-chat-agent-chip-lock-e2e.md, agent: debugger)
- [2026-09-07] apps/app chat has TWO agent-selection stores behind the flag-off `chat_ux_v2`: `agent-picker/chat-selection-context.tsx` (legacy, what e2e and prod actually run) and `session/session-store.tsx` via `session-bridges.tsx` (flag-on). Any change to selection semantics must land in both or neither — patching one looks like a fix. (source: debugger/reflections/2026-09-07-chat-agent-chip-lock-e2e.md, agent: debugger)
- [2026-09-07] A client-side 'lock' latch that mirrors server state is usually redundant AND one-way: it never releases on failure. Prefer deriving from the server-truth prop (here `hasMessages = messages.length > 0 || isStreaming`, already synchronous at submit). (source: debugger/reflections/2026-09-07-chat-agent-chip-lock-e2e.md, agent: debugger)
- [2026-09-07] Playwright role locators key on the ACCESSIBLE NAME, so a component that swaps to a read-only variant with a different aria-label (`Agent: X` -> `Agent locked: X`) presents as 'element never found', not 'element disabled'. Read the variant branches before blaming navigation/state loss. (source: debugger/reflections/2026-09-07-chat-agent-chip-lock-e2e.md, agent: debugger)
- [2026-09-10] On a Next App Router navigation trace, `Next-Router-Prefetch: 1` is the discriminator between prefetch noise and a real navigation: the navigation fetch has NO prefetch header and DOES carry `Next-Router-State-Tree`. Judging "the RSC request returned 200" without checking that header answers the wrong question. (source: debugger/reflections/2026-09-10-2559-dropped-navigation.md, agent: debugger)
- [2026-09-10] An RSC 200 proves nothing about usability — read the body: count Flight rows and check every `$L`/`$@` lazy reference resolves. An unresolved ref means React suspends forever and the URL never updates. (source: debugger/reflections/2026-09-10-2559-dropped-navigation.md, agent: debugger)
- [2026-09-10] `apps/app` runs `cacheComponents: true` (next.config.mjs) = Next 16 PPR + client segment cache, so every navigation is preceded by `/_tree`, `/_head` and `__PAGE__` segment prefetches, and dynamic routes prefetch with `$d$` FALLBACK params. Expect this shape before calling it anomalous. (source: debugger/reflections/2026-09-10-2559-dropped-navigation.md, agent: debugger)
- [2026-09-10] A steady sub-second screencast-frame cadence in a Playwright trace is not evidence of React re-rendering — an animated GIF loops in the compositor. Identify the animating asset before building a re-render theory on it. (source: debugger/reflections/2026-09-10-2559-dropped-navigation.md, agent: debugger)
- [2026-09-10] Before investigating a CI flake, check whether a red run exists AFTER the last diagnostic/instrumentation fix merged. If not, the instrumentation is unexercised and the newest artifacts may predate it — that reframes the whole task. (source: debugger/reflections/2026-09-10-2559-dropped-navigation.md, agent: debugger)
- [2026-09-11] Before mocking a Drizzle column's return shape in a test, grep its definition in `packages/database/src/schema/*.ts` first — a `{ mode: "bigint" }` column returns a JS `bigint`, not a string or number, and guessing the shape costs an extra edit cycle. (source: test-engineer/reflections/2026-09-11-action-metering-plan-allowance-tests.md, agent: test-engineer)
- [2026-09-11] A function's "never throws" JSDoc claim can be load-bearing architecture, not decoration — `packages/billing/src/bootstrap.ts`'s `setUsageRecorder` callback awaits `recordGovernedAction` with zero error handling of its own, so a missing try/catch in the callee was a real unhandled-rejection risk in the kernel's post-handler accrual path, not a cosmetic doc/code mismatch. Always check the caller before dismissing a doc-vs-code gap as harmless. (source: test-engineer/reflections/2026-09-11-action-metering-plan-allowance-tests.md, agent: test-engineer)
