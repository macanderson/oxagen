# Skill resolution core

ADR-090 is the accepted decision. Its original issue also contains an older inventory-only scope; preserve both lanes and use Refs until the expanded resolution work is complete.

The config source is the approved repository binding and its configured production branch. Never use GitHub's live default branch. Read merged configuration by merge commit, record exact-byte TOML digest, and compare the current repository's immutable provider id before trusting a reused owner/name.

Human preview selects an immutable configuration but reads skill bytes at one current repository commit. Reading every skill at the configuration commit would hide a changed digest forever. Agent replay will need both the pinned configuration and its run's repository commit.

Initial import is once per binding. A changed binding starts off until imported; old versions remain readable explicitly. Publication must recheck the active connection and binding inside the transaction. Config labels allocate under a workspace advisory lock.

Tests are written for CI. No test file ran in this lane under the task-wide one-file policy. Independent test-engineer audit by evidence_fixes approved the core after adding a real cross-workspace foreign-key refusal and preview role/binding negatives.
