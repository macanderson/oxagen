# Lessons

- [2026-09-22] When a version writer copies legacy config but stores edited source separately, use source as authority for both field changes and removals; test the active-version read through its signed output. (source: reflections/2026-09-22-budget-source-recovery.md)
- [2026-09-22] Do not symlink node_modules across worktrees with different lockfiles: pnpm can automatically recreate the donor tree. Use independent dependencies. (source: reflections/2026-09-22-budget-source-recovery.md)
- [2026-09-22] A Git credential helper that returns the vendor token transfers custody to Git. Keep the vendor request inside the daemon and give Git a repository/session lease. (source: reflections/2026-09-22-github-custody-recovery.md, agent: sso-recovery)
- [2026-09-22] Git insteadOf matches prefixes. Change exact configured remote values with restoration receipts when a similarly named repository must remain untouched. (source: reflections/2026-09-22-github-custody-recovery.md, agent: sso-recovery)
- [2026-09-22] resolveEnrolledHost permits paused/suspended hosts for control traffic. Credential minting must separately require active status. (source: reflections/2026-09-22-github-custody-recovery.md, agent: sso-recovery)
