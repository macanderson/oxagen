# Codex lessons

- [2026-09-19] Avoid running pnpm hooks against symlinked node_modules in isolated worktrees: automatic installation can mutate the shared dependency tree. Use isolated installs or direct binaries. (source: codex/reflections/2026-09-19-pr-3439-ci.md, agent: codex)
- [2026-09-19] For broad documentation cleanup, compare historical compilations to their surviving originals, separate contract declarations from mounted surfaces, and check deleted-file references before committing. (source: reflections/2026-09-19-repository-docs-cleanup.md, agent: codex)
- [2026-09-19] Keep monitoring final PR heads after external merges: a queued merge can introduce manifest drift or reveal a timing failure after the PR closes. Carry necessary repairs into a focused follow-up and verify its CI. (source: reflections/2026-09-19-active-pr-ci.md, agent: codex)
- [2026-09-19] Before filling backlog project estimates, inspect both project fields and existing build-time labels, and compare all open issues with project membership. (source: reflections/2026-09-19-backlog-triage.md, agent: codex)
- [2026-09-19] Oxagen backlog titles use priority, a middle dot, area/page, another middle dot, and a plain-language title. Keep the prefix aligned with the priority label, and open bodies with a short explanation before preserved technical evidence. (source: reflections/2026-09-19-backlog-triage.md, agent: codex)
- [2026-09-19] Consolidate by one shared behavior and completion checklist, not file overlap alone. Preserve source blocker labels, link both ways, and close source issues as not planned because consolidation does not prove a fix. (source: reflections/2026-09-19-backlog-consolidation.md, agent: codex)
- [2026-09-19] A removed source path can mean a component moved. Find the current implementation before treating the ticket as obsolete. Move planning-only tickets to the project overview only after preserving phase links, priority, freezes, and final completion checks. (source: reflections/2026-09-19-backlog-reduction.md, agent: codex)
